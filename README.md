# FoxyVerse

A futuristic cyberpunk landing page built for a digital ecosystem brand focused on AI, cloud, and streaming experiences.

## Features
- Neon cyberpunk design
- Dark premium aesthetic
- Responsive landing page
- Vercel-ready static site

## Run locally
Open `index.html` in a browser, or use any static host.

## Deploy to Vercel
1. Import this repository into Vercel.
2. Keep the default settings.
3. Deploy.
